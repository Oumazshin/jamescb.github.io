# Personal Portfolio

React portfolio website built with Vite and Tailwind CSS.

## Features

- Responsive design with animations
- Code-splitting for performance
- Error handling with boundaries
- Form validation
- Optimized event listeners

## Tech Stack

- React 19
- Vite
- Tailwind CSS 4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)

## Building

```bash
npm run build
npm run preview
```
